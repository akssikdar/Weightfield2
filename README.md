# Weightfield2
Weightfield2:  a freeware 2D simulator for silicon and diamond detector
First github page: https://github.com/fcenna/weightfield


## Parent website:  https://www.to.infn.it/~cartigli/Weightfield2/index.html

## Installation
Supported OS: Mac and Linux
(MacOS 12.5 and XCode 13.5 with root 6.26/06 or newer)

Step:
   1. Download the latest version from https://www.to.infn.it/~cartigli/Weightfield2/download.html
   2. Unzip it
   3.  In a terminal, type "make"   OR "make -f Makefile_optimized"
   4.  In the same terminal, type "./weightfield"
